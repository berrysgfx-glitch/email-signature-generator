Add it to Outlook

Outlook on the web and new Outlook
Settings → Account → Signatures → New signature. Name it, click inside the box, press Ctrl+V (Cmd+V on Mac), then Save. Pick it under default signatures.
Classic Outlook on desktop
File → Options → Mail → Signatures → New. Name it, click in the edit box, press Ctrl+V, then OK.
